# Duolingo Score and Lang Weave placement

Reviewed November 17, 2026. For initial placement, offer an optional learner-entered Duolingo Score alongside direct Lang Weave placement and an optional vocabulary check. Assume a single selected target and a Lang Weave-owned vocabulary pack. A score can guide where to start introducing words. Per-word knowledge and review schedules need evidence from the learner.

## Unofficial Python clients

Reviewed November 19, 2026 using public source and the published wheel. Current account responses remain unverified.

- **Kartik Talwar’s `duolingo-api`.** PyPI lists 0.5.4 (March 2021) as the latest release. `get_language_details("French")` returns a matching legacy language record. The README shows level 6 and 604 points. `get_language_progress("fr")` requests a fixed set of fields including points, progress toward the next XP level, skill count, and legacy `fluency_score`. The published code requires account authentication. These methods select by target name or code and offer no documented current Duolingo Score, CEFR result, or teaching-language selector. The raw details record could pass through other fields if the upstream supplied them. [PyPI release](https://pypi.org/project/duolingo-api/0.5.4/), [client examples](https://github.com/KartikTalwar/Duolingo/blob/9e552ba4b03be8dff44e1de6e55d7c845d53c897/README.md#get-language-details), [client source](https://github.com/KartikTalwar/Duolingo/blob/9e552ba4b03be8dff44e1de6e55d7c845d53c897/duolingo.py#L370)
- **Legacy vocabulary.** `get_known_words("fr")` deduplicates words attached to skills marked learned in the old tree. Those words could help select candidates for a placement check if the course and vocabulary match, but they describe course exposure and give no individual recall evidence. XP can accumulate through practice independent of path position. [Client source](https://github.com/KartikTalwar/Duolingo/blob/9e552ba4b03be8dff44e1de6e55d7c845d53c897/duolingo.py#L432), [Duolingo skill-tree research](https://research.duolingo.com/papers/portnoff.edm21.pdf)
- **TerraFaster’s `Duolingo-Wrapper`.** The Python source models teaching and target languages, active section and unit indices, and completion counts. A source comment illustrates a nullable section `cefr` object with a B1 score range of 60–79. The section parser omits that object. If a learner supplies an independently mapped position from the same course pair and revision, the section band can suggest vocabulary difficulty. The example range describes a section and leaves the learner’s exact Score unknown. [Active course parser](https://github.com/TerraFaster/Duolingo-Wrapper/blob/95b238044a169f5672b70ce8c7930f0ddc14f210/duolingo/active_course.py#L60), [section parser and example](https://github.com/TerraFaster/Duolingo-Wrapper/blob/95b238044a169f5672b70ce8c7930f0ddc14f210/duolingo/course_section.py#L31)

For example, a learner who reports a displayed Score of 42 for Spanish from English has reached A2-aligned course content under Duolingo’s scale. Use that as the starting difficulty for a short Spanish vocabulary check if the pack supports it, and adjust from the learner’s answers. A legacy level of 6 provides no basis for the same mapping. [Duolingo Score guide](https://blog.duolingo.com/duolingo-score/)

## Course direction and coverage

Record the target language and the course's teaching language as an ordered pair when both are known. Spanish taught from English is different from English taught from Spanish. A Spanish-taught Guaraní learner can still use Lang Weave's English-source reading. Only the target must match for a placement hint. Pair-specific mappings need independent evidence before using another course's position or vocabulary. Use the current Score if shown. A section or unit number can help the learner describe their background, but its meaning depends on the course and revision. Duolingo has already changed how units are grouped. [Duolingo course structure](https://blog.duolingo.com/duolingo-101-how-to-learn-a-language-on-duolingo/), [mini-unit changes](https://blog.duolingo.com/intermediate-mini-units/), [Lang Weave language boundary](../LANGUAGE-API.md)

Duolingo's 2025 recap says Score launched to all language courses. Its 2026 coverage article says most learners in nine named languages can reach 129, the end of B2. These statements do not resolve current course availability, score coverage, or caps for each pair. Guaraní was launched as a Spanish-taught Jopará course. The course contributor described that variety explicitly. This review could not verify current enrollment or Score display for that pair, or an English-taught Guaraní course. Provide direct placement for Guaraní without requiring any Duolingo data. [2025 recap](https://blog.duolingo.com/product-highlights/), [2026 coverage](https://blog.duolingo.com/courses-teach-advanced-content/), [launch announcement reproduced by La Nación](https://www.lanacion.com.py/2016/09/15/duolingo-agrega-guarani-jopara-cursos/?outputType=amp), [course contributor interview](https://www.aymara.org/lengua/2016/liz-sanchez-adaptamos-duolingo-al-guarani-y-no-al-reves/)

## What the score can estimate

Duolingo's bands are 0–29 for A1, 30–59 for A2, 60–99 for B1, and 100–129 for B2. Its published scale groups 130–160 as C1/C2, distinct from available course coverage. These bands can guide the difficulty of the first words sampled in a Lang Weave curriculum with its own difficulty labels. The score alone does not establish how many words the learner knows, which ones they recognize, or how well they can recall them. CEFR describes communicative ability and vocabulary range, with no universal word-count thresholds. Duolingo's Practice tab can show vocabulary for practice, which measures a different thing from a tested recall count. XP and streak measure activity. [Duolingo Score guide](https://blog.duolingo.com/duolingo-score/), [Council of Europe CEFR (2001), §§5.2.1.1 and 6.4.7.1](https://rm.coe.int/16802fc1bf), [Duolingo Practice guide](https://blog.duolingo.com/guide-to-duolingo-practice-hub/)

The smallest useful estimate is a starting difficulty band. Probe a few familiar and unfamiliar written forms from neighboring bands within the selected Lang Weave pack, with an “I don't know” option. Use the learner's responses and chosen challenge level to adjust which new words appear. If a future feature reports a numerical estimate, define the catalog, counting unit (such as distinct target lemma and sense), and tested skill first. Sample across relevant bands, extrapolate only to that catalog, and show uncertainty. A short placement check can rank candidates without supporting a credible individual word count. [Vocabulary test sampling research](https://journals.sagepub.com/doi/10.1177/0265532220979562)

## Enrollment and correction

1. Choose a target and load its available vocabulary. Offer direct placement, the optional check, or manual Score entry. For Score entry, ask for the course target, its teaching language if known, and the displayed whole number within 0–160. Offer direct placement if there is no valid score or the course target is uncertain or differs from the selected target. Any saved Score is a local self-report tied to the supplied course information and observation date.
2. Preview a concrete choice with example words and an easier or harder option before applying it. Use a documented mapping only where the available pack has suitable local difficulty bands. Bundled Spanish currently has beginner and expanded vocabulary, so present those choices in product terms. For unsupported or limited packs, offer placement within available content. A high external score cannot add words the pack lacks. [Lang Weave design](../DESIGN.md)
3. Set the placement for future introductions within the existing language and pack scope. Keep already introduced items reviewable, with their existing FSRS state, due dates, events, and counters. Changing the placement should be reversible, safe to repeat, and affect only future selections. An older placement suggestion or result from another scope must not override the current choice. The existing full-history versus candidate boundary provides the model. [Adaptive selection contract](../ADAPTIVE-MISSION.md), [learning storage and portability](../STORE-PORTABILITY-MISSION.md)
